Import rapide par classe
Choisissez la classe cible ci-dessous, puis importez toute votre liste Excel. Dans ce mode, la colonne Classe n’est pas nécessaire : tous les élèves du fichier seront affectés à la classe sélectionnée.

Formats acceptés : CSV et XLSX, avec virgule, point-virgule ou tabulation. Colonnes reconnues : Nom complet ou Nom + Prénom, Matricule, Classe ou Code classe, Sexe, Date de naissance, Lieu de naissance et Redoublant. Laissez la classe cible vide uniquement si votre fichier contient une colonne Classe ou Code classe différente pour chaque élève.
