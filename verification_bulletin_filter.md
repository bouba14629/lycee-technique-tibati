# Vérification du filtre Filière dans les bulletins

Le rendu fonctionnel généré sur une base temporaire confirme que le formulaire affiche les contrôles dans l’ordre **Filière**, **Classe**, puis **Période**. La filière « Électricité — ELEQ » est correctement sélectionnée et la liste Classe ne contient que « 2nde ELEQ » ; la classe « 2nde MA » d’une autre filière est absente.

Une seconde série de captures a ensuite été réalisée avec les feuilles de style réelles de l’application intégrées localement. Sur desktop, les trois contrôles sont alignés dans la carte Bulletin avec une hiérarchie claire. Sur le viewport mobile de 390 × 844 pixels, les menus **Filière**, **Classe** et **Période** s’empilent proprement, restent lisibles et ne provoquent aucun débordement horizontal.
